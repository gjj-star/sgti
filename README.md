# SGTI - Stellaris Government Type Indicator

群星政体性格测试 — 找出你在群星宇宙中的政体归属

[![SGTI](https://img.shields.io/badge/SGTI-v2.0-blue)](https://github.com/gjj-star/sgti)
[![Stellaris](https://img.shields.io/badge/Inspired%20by-Stellaris-gold)](https://www.paradoxinteractive.com/games/stellaris)

## 简介

SGTI 是一个以游戏《群星》(Stellaris) 为主题的性格测试，类似于 MBTI 但完全基于群星的意识形态体系。通过回答 40 道题目，测试你在群星宇宙中的政体归属。

## 特点

- **42 种政体**：银河帝国、集体意识、肃正协议、寰宇企业、星际联邦、铁心灭绝者等
- **6 个评估维度**：权威-平等、排外-亲外、军国-和平、唯心-唯物、扩张-孤立、集体-个人
- **5 点量表**：从😠强烈反对到😊强烈赞同
- **群星梗满满**：融入"血肉苦弱，机械飞升"、"开门，自由贸易！"、"净化是一种态度"、"巨像一发入魂"等经典社区梗
- **精美 UI**：星空动画、群星风格配色、跃迁动画效果
- **丰富结果页**：意识形态光谱、政体宣言、推荐游玩风格、历史对标、彩蛋

## 使用方法

直接在浏览器中打开 `sgti.html` 即可开始测试。

### 快捷键

- `1-5`：选择答案
- `Backspace`：返回上一题

### 功能

- **快速模式**：20 道精简题目
- **进度保存**：自动保存答题进度，可随时继续
- **分享卡片**：生成精美结果图片
- **彩蛋政体**：极低概率触发的秘密政体
