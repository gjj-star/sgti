# SGTI 政体像素艺术角色提示词

> 基于群星6维轴的"视觉翻译规则"，为42种政体生成的像素艺术角色提示词。
> 所有提示词均为英文，可直接用于 Midjourney / Stable Diffusion / DALL-E。

---

## 视觉翻译词典 (SGTI 6维轴 → 视觉元素)

### 轴1：权威 (Authority)
- **威权端 (Authoritarian)**：皇冠、权杖、高耸体型、俯视视角、金色装饰、铠甲、披风
- **平等端 (Egalitarian)**：投票箱、握手、平视视角、便装、围巾、标语牌

### 轴2：排外 (Xeno)
- **排外端 (Xenophobe)**：盾牌、围墙、面罩、封闭构图、冷色调、尖刺
- **亲外端 (Xenophile)**：多色混搭、异族伙伴、开放姿态、彩虹色、握手/拥抱

### 轴3：军国 (Militarism)
- **军国端 (Militarist)**：武器、盔甲、战斗姿态、红色/深色调、伤疤、勋章
- **和平端 (Pacifist)**：橄榄枝、花朵、放松姿态、绿色/天蓝色、微笑

### 轴4：唯心/唯物 (Spirituality)
- **唯心端 (Spiritualist)**：长袍、水晶球、星座符号、神秘光晕、宗教符号
- **唯物端 (Materialist)**：护目镜、实验瓶、全息屏幕、齿轮、芯片、数据流

### 轴5：扩张 (Expansion)
- **扩张端 (Expansionist)**：星图、望远镜、展开的卷轴、向前迈步
- **孤立端 (Isolationist)**：封闭空间、窗户紧闭、蜷缩姿态、围墙/壳

### 轴6：经济 (Economy)
- **集体端 (Collectivist)**：统一制服、方阵、相同面具、蜂巢图案
- **个人端 (Individualist)**：独特服饰、花哨配饰、自由姿态、涂鸦风格

### 背景色指南
- 威权/军国 → 深红、暗金、铁灰
- 平等/和平 → 天蓝、浅绿、米白
- 排外 → 暗紫、深灰
- 亲外 → 暖橙、明黄、彩虹
- 唯心 → 星空紫、月白
- 唯物 → 科技蓝、荧光绿
- 扩张 → 深空蓝、星云色
- 孤立 → 银灰、暗青
- 集体 → 统一灰、蜂巢金
- 个人 → 随机彩色、涂鸦墙

## 使用说明

1. **直接复制**上方任意政体的提示词，粘贴到 Midjourney / SD / DALL-E 中即可生成
2. **负面提示词**：所有政体通用 `realistic, 3D, photo, blur, curved lines, gradient, complex background, messy, watermark, text`
3. **Midjourney 建议**：追加 `--style cute --niji 6` 获得更好的可爱画风
4. **Stable Diffusion 建议**：使用 Pixel Art LoRA 模型，CFG Scale 7-9，Steps 30+
5. **尺寸**：所有提示词默认 `--ar 1:1` (正方形)，适合做头像/卡片
6. **背景色**：每种政体都根据其意识形态特征选择了匹配的背景色，保持视觉统一性
